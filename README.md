# CZN Launcher Lite

Chaos Zero Nightmare（卡厄思梦境）国际服第三方极简启动器.

> **免责声明**：本项目为非官方第三方工具，与 Smilegate / STOVE 无任何关联。

> 一切后果由使用者自行承担。

## 快速开始

**使用打包版**

1. 解压后确认 `config.json` 与 exe 位于同一目录
2. 运行 `czn-lite-flet.exe`
3. 点「获取离线信息」自动探测游戏安装路径，探测不到可点「选择游戏路径」手动指定
4. 点「扫码登录」，用手机 STOVE App 扫码,已支持账号密码登录，输入账号密码登录并完成验证码（stove要求验证码，第三方启动器只做转发和ui交互优化）后效果等同扫码登录
5. 点「启动游戏」

**从源码运行**

```bash
pip install -r requirements.txt
python gui_flet.py     # 图形界面（Flet / Material 3）
python czn_lite.py     # 控制台版
```

## 两种登录方式

| 方式 | 说明 |
|---|---|
| **扫码登录** | 用手机 STOVE App 扫码。**推荐**，无需输入账号密码 |
| **账号密码登录** | 在启动器内输入 STOVE 账号密码。首次通常会要求做人机验证码 |

### 关于账号密码登录

STOVE 的账密登录在服务端会要求**交互式人机验证码**（点选形状 / 旋转对齐），
启动器会弹出一个窗口让你作答。这类验证码**无法自动识别**（属于 CV 任务），
必须人工点一下。

## 环境要求

- Windows 10/11 x64
- 已安装游戏本体
- 源码运行需要 Python 3.12

## 配置

全部配置集中在 `config.json`。所有配置信息和账号信息本地明文保存。

| 键 | 说明 |
|---|---|
| `game.install_root` | 游戏安装目录；用「获取离线信息」自动探测，或用「选择游戏路径」手动指定 |
| `game.game_exe` | 游戏主程序相对路径（默认 `bin\ssr-stove-shield.exe`），启动与路径检测都以它为目标；游戏版本改名时改这一项 |
| `platform.caller_id` | 官方客户端版本串 |

`state.json` 由程序自动生成，内含登录凭据，**等同账号密码，切勿外传**。

> 手动选择游戏路径时，选**包含 `bin` 子目录的那一层**。选错层级（指到
> `bin` 或某个 exe）启动器会自动上跳纠正，并在日志里写明。

## 网络与代理

默认**直连**（显式锁定，不受系统代理与 `http_proxy` 等环境变量影响）。需要时点状态栏右侧「网络」切换，或改 `config.json` 的 `network.mode`：

| 值 | 说明 |
|---|---|
| `direct` | 直连（默认） |
| `system` | 跟随系统代理（支持静态代理、PAC、WPAD） |
| `manual` | 手动指定，如 `socks5://127.0.0.1:1080` |

覆盖范围：**启动器的全部出站请求**都走这一条路 —— 登录 / 令牌兑换、扫码轮询、
验证码素材与提交。已实测核验：把 `network.mode` 设成指向死端口的手动代理后，
上述每一类请求都改走该代理（`ConnectionError … over proxy 127.0.0.1:9`）。
**不含**游戏进程自己的流量 —— 那是游戏引擎的 curl，需要代理请用系统代理/TUN。
