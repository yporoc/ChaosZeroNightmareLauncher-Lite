# CZN Launcher Lite

Chaos Zero Nightmare（卡厄思梦境）国际服第三方极简启动器.

> **免责声明**：本项目为非官方第三方工具，与 Smilegate / STOVE 无任何关联。
> 仅供个人学习研究，禁止商业用途。使用本项目可能违反游戏服务条款并带来账号风险，
> 一切后果由使用者自行承担。

## 快速开始

**使用打包版**

1. 解压后确认 `config.json` 与 exe 位于同一目录
2. 运行 `czn-lite-gui.exe`
3. 点「获取离线信息」自动探测游戏安装路径
4. 点「扫码登录」，用手机 STOVE App 扫码
5. 点「启动游戏」

**从源码运行**

```bash
pip install -r requirements.txt
python gui.py          # 图形界面
python czn_lite.py     # 控制台版
```

## 两种登录方式

| 方式 | 说明 |
|---|---|
| **扫码登录** | 用手机 STOVE App 扫码。**推荐**，无需输入账号密码 |
| **账号密码登录** | 在启动器内输入 STOVE 账号密码。首次通常会要求做人机验证码 |

### 关于账号密码登录

STOVE 的账密登录在服务端会要求**交互式人机验证码**（点选形状 / 旋转对齐），
启动器会弹出一个窗口让你作答。这类验证码**无法自动识别**（属于 CV 任务），
必须人工点一下。

## 环境要求

- Windows 10/11 x64
- 已安装游戏本体；没装过 STOVE / 游戏也可以用「全新安装」从 0 装起
- 源码运行需要 Python 3.12

## 配置

全部配置集中在 `config.json`。所有配置信息和账号信息本地明文保存。

| 键 | 说明 |
|---|---|
| `game.install_root` | 游戏安装目录，或用「获取离线信息」自动探测 |
| `platform.caller_id` | 官方客户端版本串 |

`state.json` 由程序自动生成，内含登录凭据，**等同账号密码，切勿外传**。

## 网络与代理

默认**直连**（显式锁定，不受系统代理与 `http_proxy` 等环境变量影响）。需要时点状态栏右侧「网络」切换，或改 `config.json` 的 `network.mode`：

| 值 | 说明 |
|---|---|
| `direct` | 直连（默认） |
| `system` | 跟随系统代理（支持静态代理、PAC、WPAD） |
| `manual` | 手动指定，如 `socks5://127.0.0.1:1080` |

覆盖范围：**启动器的全部出站请求**都走这一条路 —— 登录/令牌、DPMS 清单与补丁下载、
版本探测、`buildInfo` 旁证、资源层入口 API、以及全新安装时下载微软官方前置安装器
（`vc_redist` / WebView2 引导器）。已实测核验：把 `network.mode` 设成指向死端口的
手动代理后，上述每一类请求都改走该代理（`ConnectionError … over proxy 127.0.0.1:9`）。
**不含**游戏进程自己的流量 —— 那是游戏引擎的 curl，需要代理请用系统代理/TUN。

## 日志与反馈

界面日志**明文**（含凭据，请勿直接外发）；「导出日志」导出的是**已脱敏**的反馈日志，可直接发送。

## 游戏资源与更新

底栏 **「下载游戏资源与更新」** 里有三个动作，**全部手动触发 —— 启动游戏不会检查、也不会下载**：

| 动作 | 做什么 |
|---|---|
| **检查更新** | 查本体（`bin\` 受管文件）有没有新版；资源层（`bin\appdata\cznlive`）逐组比对本地/远端修订。只读 |
| **校验完整性** | 本体受管文件逐个「存在 + 大小 + MD5」。只读；发现缺失/损坏才问你要不要补回 |
| **全新安装** | 体检磁盘 / VC++ 2022 x64 / WebView2 → 按官方清单装本体（约 269 MB） |

- 只改变动过的文件，支持断点续传；每个文件要过**压缩包 MD5 + 解压后 MD5** 才替换
- 替换前留 `.cznbak` 备份、同目录改名生效；版本号最后写 = 「本次已提交」标记
- **约 5.5 GB 资源数据包由游戏自己在首次运行时下载**（官方同款流程），启动器不下载、不写回，只汇报进度
- 同版本下「与官方不同但大小一致」的文件按你的补丁/汉化保留；代价是下次用官方 STOVE 启动会重下覆盖。想反过来就设 `update.restore_modified = true`
- 建议先登录再检查更新：登录后走官方权威版本接口；未登录只能用清单探测，CDN 回 403 时会如实报「无法确认」而不是假装已最新
- 命令行：`python update.py --check | --verify | --update | --install | --gamedata`
- 配置在 `config.json` 的 `update` 段，都有默认值：`auto_download` `verify_mode` `workers`
  `resume` `backup_before_replace` `restore_modified` `keep_temp` `probe_fallback`
  `check_vcredist` `buildinfo_check` `gameres_*`
- 网络设置管辖一切：以上所有出站请求（含微软前置安装器的下载）都走「网络」按钮里的直连/系统代理/手动代理
